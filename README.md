# Enterprise AI Support & Knowledge Agent

An AI-powered enterprise support assistant that combines
REST APIs, structured enterprise data, RAG, and Agentic AI
to help support teams investigate customer issues.

## Project Status

🚧 Currently under development


## Planned Features

- Python backend
- FastAPI REST APIs
- PostgreSQL database
- SQL-based data validation
- LLM integration
- Retrieval-Augmented Generation (RAG)
- Agentic AI with LangGraph
- Automated testing
- API testing
- Performance testing
- Docker
- CI/CD
- Cloud deployment

## Current Features

- FastAPI backend
- REST API endpoints
- PostgreSQL database
- Customer management
- Order management
- Product management
- Support ticket management
- SQL-based data validation

## Database

The application uses PostgreSQL to store:

- Customers
- Orders
- Products
- Support tickets

The database uses foreign-key relationships
to maintain data integrity.
